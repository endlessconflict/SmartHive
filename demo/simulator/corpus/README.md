# Demo frames

Three single-bee photographs of the BeeAlarmed BeeDataset side by side, built by `../build_corpus.py` (the
dataset file behind every tile is in `MANIFEST.tsv`). A frame is here only when the project's detector finds
what the dataset's label says.

BeeDataset: https://github.com/BeeAlarmed/BeeDataset, GPL-3.0, by Fabian Hickert (2021), "Dataset for a camera
based bee-hive monitoring". Its images are redistributed here under that licence.

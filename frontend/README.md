# frontend/

Responsive web dashboard: hive overview, history charts, latest image, alerts.

Status: Planned. The API it consumes is described in [docs/05-backend/06-api-design.md](../docs/05-backend/06-api-design.md). Framework choice and UI design are scheduled in the [roadmap](../docs/roadmap.md).

Development does not need hardware: run the Docker Compose `dev` profile, which starts the hive simulator and fills the API with synthetic hives.
